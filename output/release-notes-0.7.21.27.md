# Folia 0.7.21.27 更新日志

这一版把「屏幕常亮」修好了，补上带两种关闭方式的定时关闭，并加入「全部音源」搜索、播放失败自动换源、队列融合与平台徽章。

## 屏幕常亮：这次是真的常亮了

上一版的常亮只走了浏览器的 Screen Wake Lock，而这条 API 要 Chrome 84 才有 —— 车机与老平板的 WebView 大多停在 70 上下，开关看着是开的，屏幕照旧灭。同时那个锁被系统释放之后引用没清掉，回前台再也申请不回来。

现在改成一主一备两条通道：主通道是 Android 窗口标志 `FLAG_KEEP_SCREEN_ON`（新增的原生方法 `setKeepScreenOn`，回前台时在 `onWindowFocusChanged` 里重新贴一次），备通道才是浏览器的 Wake Lock；锁被系统收走时把引用清空，下次点亮可以重新申请。只有「正在播放」时才会持有，暂停即释放。

开关现在有两个入口，读写同一个字段，在哪边改都一致：

- 面板 → 控制页 → 屏幕常亮
- 设置 → 播放 → 行为

## 定时关闭：两种关闭方式

面板控制页与服务端设置页都加了这一组：

- 快捷时长 15 / 30 / 60 / 90 分钟，右侧可以按 5 分钟为单位自定义（上限 999 分钟）。
- **关闭方式**两种：**播完整首歌后关闭**与**直接关闭**（默认保持原来的行为，到点即停）。选前者时，到点不会拦腰截断正在放的这首，而是先挂起、等这首放完再停；那段时间面板上的倒计时会显示「已到点，等这首放完就停」。暂停状态或已经没有音频在放时，到点照旧立即执行。
- 关掉定时会连「等这首放完」的挂起状态一起清掉，不会在下一次放完时莫名停下来。

## 搜索：全部音源

搜索页的来源多了一项「全部音源」：一次搜遍所有已登录且支持搜索的平台，不必先切账号。各平台并发请求、按名次交错合并再按歌名去重，所以不会出现前排被单一平台占满；某个平台失败不影响整体结果，只有一个都问不到时才报错。命令面板里的「搜索当前来源」在选了「全部音源」时也保持这个范围，不会缩回单个平台。

## 播放失败：自动到别的音源找同一首

歌曲下架、没有音频、音频放不了、只有试听、要会员、要购买、要权限、地区限制这几种，以前只能报一句「放不了」。现在会先在本平台找同一首的其它版本（原有逻辑），找不到就去别的已配置平台搜同一首：

- 匹配刻意保守：歌名去掉括号补充与标点后必须完全相同，再要求歌手重合，或时长相差不超过 5 秒。换错一首比跳过一首更让人困惑。
- 命中之后直接把队列里这一条换成那边的歌、接着放，提示条写明是从哪个平台找到的。
- **一首歌只换一次**：如果换过去那边也放不了，就按正常失败处理，不会在两个平台之间来回弹。
- 连不上、未登录、未配置这几种不换 —— 换个平台不会让它们变好。

播放中途失败（媒体解码、音频不可播放）走同一套匹配，只是会从那首的开头重新放。

## 队列融合与平台徽章

- 切换在线平台不再清空播放队列：队列与正在放的那首原地保留，只重置搜索与集合导航。退出登录仍然会清空队列，那是另一回事。
- 打开在线歌单点「播放全部」时，新歌单**并入**当前队列（已在队列里的不重复添加），并提示「已并入当前队列（N 首）」，不再把排好的歌换掉。
- 队列拼贴墙与搜索结果行都按歌曲来源显示平台徽章，混着几个平台的队列一眼能看出哪首来自哪家。

## 网易云歌词：被风控时重试与降级

歌词接口返回 `code 2001`（操作频繁）、`-460`（请求异常）、`-447`（登录被风控）或 HTTP 429 时，以前是直接把空歌词交给界面。现在这几种按可重试处理：等 700ms 再要一次，还不行再等 2000ms 要一次，仍然被拦就降级到老接口 `/lyric?id=` 再试 —— 它要求的字段少，常常还能给。云盘歌曲的歌词拿不到时也会回落到普通歌词路径，而不是直接判成没有歌词。三种路径都拿不到，才按「没有歌词」显示。
