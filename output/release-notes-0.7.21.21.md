# Folia 0.7.21.21 更新日志

## 播放破音

- **主链路新增软限幅（保险）**：整条链最后、进扬声器之前加了一级软限幅。此前每一级都可能把信号推过满刻度 —— 网易云只给 ReplayGain 的 gain、不给 peak，正向增益没有削波保护；均衡器多段同时提升；效果链的 punch 补偿增益；交叉淡化时两轨相加 —— 而系统的输出端只会硬削波，听到的就是「破音」。现在 0.95 满刻度以下严格直通（实测 0.5 倍信号进出都是 0.5000），以上用平滑曲线压住：实测 2 倍、4 倍、8 倍过载信号走完整条图，没有任何一个样本越过满刻度。
- **没有峰值信息时不再放大**：ReplayGain 的峰值是判断「放大了会不会削波」的唯一依据。缺失时（网易云只给 gain）以前会照搬正向增益，现在只衰减、不放大 —— 宁可轻一点，也不破音。

## 播放卡顿

- **音频缓冲加大**：音频上下文从默认的低延迟档改为 `playback` 档。默认档为压低延迟只用很短的输出缓冲，手机上主线程一抖（可视化一帧算得久、React 一次大重渲染、GC 一次回收）缓冲就见底，听到的就是断断续续。播放器不需要「手势到出声」的低延迟，用一点延迟换不断音。
- **终止每帧分配内存**：可视化音频桥每秒 60 次循环里原本每帧新建一块 1KB 的频谱数组，现在复用同一块。减少的垃圾会让 GC 少被唤醒，那种「偶尔一顿」的停顿来源之一就此消失。
- **续播护栏只操作当前 deck**：原生侧每秒的焦点续播护栏原来取 DOM 里第一个 `<audio>`，第一次交叉淡化之后活动 deck 变成 B，第一个是已经停下来的 A —— 护栏会去 `play()` 那条本该安静的热备 deck，白解码一首旧歌还让它的位置一路漂。现在按 `data-folia-active-deck` 只续播真正在发声的那一路。

## 验证方式

- 单元测试新增两条：限幅曲线（直线区透明、峰值到不了满刻度、单调）与 ReplayGain 增益选择（无峰值不放大、有峰值按剩余余量放）。
- 用 OfflineAudioContext 实测：单级限幅与整条链（音量→淡入→限幅→分析→输出）都不产生越界样本。
- 应用冒烟：两个 deck 正确，活动 deck 标记正确，无运行时错误。
