# Folia 0.7.21.20 更新日志

## 浮层按钮拖动调整（四颗按钮 + 信息条）

- **拖动更跟手**：修复了拖动时按钮「拖着尾巴追手」的问题。右下角定位按钮原先对 `left/top/width/height` 也做 300ms 过渡，每帧位移都在被动画吞掉；现在过渡只保留颜色 / 透明度 / 变换，位置与尺寸即时生效。
- **触屏不再被抢手势**：拖动框与缩放手柄补上 `touch-action: none`。之前在触屏上拖动会被浏览器滚动手势（墙本身是可拖的无限拼贴）打断，拖动时断时续。
- **框体与控件同步**：拖动过程中框体按算好的绝对位置即时更新，不再等下一帧测量，视觉上与手指严格同步。
- **信息条上下两部分现在也能拖动**：开启「拖动调整位置」后，除四颗按钮外，bravais 信息条的上部分（首页窄缝标题区 / 完整信息条面包屑行）与下部分（工具坞 / 动作行 / 海报页底部）也会出现可拖动框，直接拖着挪。
- **信息条位移覆盖全部层位**：修正了 CSS 里四条永不生效的死选择器（书脊与海报的类名写错），海报页底部（真实类名 `bravais-poster-bottom`）此前无法随设置移动，现已补上。

## 浮层大小

- **四颗按钮统一一个比例**：左上角返回、右下角定位、右下角工具、思索按钮共用同一档百分比（各自基准尺寸不变，只统一比例）。此前四颗各一个滑块，记不住哪颗调过、调多少。设置里收敛为一个「四颗按钮大小」滑杆，拖动调整位置时的缩放手柄改的也是这一档。

## 设置弹窗

- **拖动调整位置开关默认关闭**：此前默认开启，浮层上一直挂着虚线框，容易误触。现在默认关闭，需要时在「主页与歌单 → Bravais 墙面 → 浮层位置」里打开；开关状态会被记住。
- **设置弹窗毛玻璃**：弹窗面板改为高斯模糊（默认 18px 模糊 + 86% 不透明度），透出背后的墙面内容。
- **模糊度与不透明度可调**：「通用 → 启动与窗口」新增「设置弹窗模糊」（0–40px，0 为纯色面板）与「设置弹窗不透明度」（40–100%）两个滑杆，拖动即时预览。
- 分组滑动指示线开关（「通用 → 启动与窗口 → 显示分组滑动指示线」）保持不变：关掉后设置弹窗顶部分组标签（外观 / 播放页等各组）下方那条跟随选中的横线消失，选中态仍由文字颜色表示。

## 其他

- 思索按钮热区按实际位置与尺寸现算的逻辑不变，统一比例后依旧正确跟随。
