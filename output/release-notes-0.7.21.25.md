# Folia 0.7.21.25 更新日志

这一版加了三通道更新，并整理了几个设置与墙上的小问题。

## 更新通道：正式版 / 内测版 / 测试版

设置 → 通用 → 在线更新里多了一项「更新通道」。三条通道发在同一个发布页，靠版本标号区分：

| 通道 | 版本标号 | 收到什么 |
| --- | --- | --- |
| 正式版 | `v0.7.22.0` | 只收正式发布 |
| 内测版 | `beta-v0.7.22.0` | 内测包 + 正式发布 |
| 测试版 | `dev-v0.7.22.0` | 测试包 + 内测包 + 正式发布 |

- 一个包就够：通道是应用内的设置，不用换安装包，覆盖安装照旧。换通道后下一次检查立即生效。
- 向下兼容：内测版用户在正式版发热修时也能收到，不会因为「正式版发了新版」而卡在旧的内测包上。
- 内测 / 测试的发布在发布页上标为「预发布」，不会被当成正式最新版；应用内按标号前缀自己挑，两边互不干扰。
- 换通道会清掉之前「稍后提醒」的记录 —— 那是另一条通道上的版本。

发布时指定通道：`scripts/publish-android-release.sh <apk> <notes> <version> beta`（省略通道就是正式版）。

## 定位按钮偶尔变成方形

根因是 Lattice 的一条样式：墙上的内容要贴成直角，所以有一条
`.lattice-queue-root *:not(.lattice-tools *):not(.lattice-back):not(.lattice-chrome button) { border-radius: 0 !important }`。
豁免名单里只有工具按钮、返回按钮那一圈，而定位按钮在 0.7.21.22 已经从工具按钮的竖列里搬出来、有了自己的锚点，
于是掉出了豁免范围，被这条规则压成直角。这条样式只在 Lattice 的样式加载之后才生效，所以表现是「偶尔」变方、
并且连它里面的定位光环一起变成方框。现在把定位按钮整棵子树加进豁免名单。

## 设置

- 「浮层位置与大小」里那两个单独占一行的「全部复位」不再单独成行：位置复位的按钮并进「编辑浮层位置」那一行，
  大小复位的按钮并进「四颗按钮大小」那一行。
- 两处复位都要二次确认：位置与大小都是一点点拖出来的，误触一次就得重来。
- 设置里的下拉列表再透一点（68%），能看见背后模糊过的内容。
