# Folia 0.7.21.28 更新日志

这一版修好了定时关闭，给主页与歌单页加了双指缩放，折叠组的毛玻璃可以单独调，另外动了拖动时偶尔闪一下的问题。

## 定时关闭：两个真原因

上一版加了定时关闭，但很多人点了开关没反应。查下来是两个问题，都不是「到点算错」（那段逻辑单测验证过是对的）：

**一、没设时长时，开关什么都不做。** 以前点了开关只弹一句「先设个时长」就结束了，而面板上的开关就在时长那一行上面一行，很容易让人以为开关坏了。现在打开时会自动补一个 15 分钟，并提示「没设时长，先按 15 分钟开始」。

**二、手机在后台会冻住计时器。** 定时关闭最典型的用法就是锁屏听着睡着，而 Android 的 WebView 在后台会把 `setInterval` 冻住甚至清掉，到点那一下整个被跳过。现在到点只有一个出口，由三条路进来：每秒一次的心跳、页面重新可见、窗口重新获得焦点。回前台会立刻核一次，不用再等下一秒。

## 主页与歌单页：双指缩放

在墙面上用两根手指捏合就能放大缩小，触控板上是双指捏合或按住 Ctrl 滚轮。缩放锚在两指中点：那一点下面的内容不动，看起来是「从这里放大」，而不是整面墙跳一下。

- 倍率夹在默认档位的 0.7 到 2.4 倍之间。
- 开关在**设置 → 主页与歌单 → 主页 → 双指缩放**，默认打开。关掉之后墙只平移，第二根手指不再触发缩放。
- 缩放倍率不保存，重开应用回到默认档位。

说明：缩放做在 Bravais 墙面（主页与歌单页共用这一面墙）。如果资料库界面选的是「Grid 网格」，那是另一套 3D 卡片流，没有这一项。

## 折叠组的毛玻璃可以单独调

**设置 → 通用 → 启动与窗口**里新增两项：折叠组卡片的模糊半径与不透明度，与上面的面板模糊/透明度分开存。

理由是卡片浮在面板之上，是第二层玻璃：面板调得很透时，卡片需要更实一点才看得清行文字；反过来面板很实、背后没有东西可透时，卡片的模糊只是白花钱。默认值与改动前一致（18px / 72%），不动就是原来的样子。

## 拖动时偶尔闪一下、抖一下

墙的世界层一直把位移吸附到整设备像素 —— 代码里写着理由：图层没有 `will-change` 时，位移的小数部分一变，浏览器就把整层丢掉重新栅格化。但「缝」（主页与歌单页真正的内容栏）的位移是手写的小数，绕过了这套吸附，拖动时它每帧重新栅格化，文字发虚、偶尔闪一下。

这一版把缝的位移与宽度也吸附到整设备像素，并且在缝变形的那几帧临时撤掉它自身的 18px 高斯模糊（模糊每帧都要按新尺寸重新采一次背后的画面，是这个界面里最贵的一笔），停下 140 毫秒后恢复。另外跳过了一部分没有变化的样式写入。

这条属于「照机制下手」：我们没有在你那台设备上复现到「偶尔」的时序。如果还有，请说清楚它发生在什么时候（拖动中 / 停手后 / 打开歌单时 / 切页签时），再往下查。
