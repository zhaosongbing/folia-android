# Folia 0.7.21.23 更新日志

## 编辑态：蒙层与像素微调

- **黑白灰三种蒙层**：顶部工具栏新增「蒙层」，点一下循环 无 → 黑 → 白 → 灰。压在墙与封面上，按钮的边界从背景颜色里浮出来，贴边与对齐时更容易判断。选择会被记住，只在编辑态生效。
- **像素级微调**：选中一个框后，底部第一行是四个方向的微调按钮，每次 1px；按住不放约 0.4 秒后开始连发。拖动只能粗放到「差不多」，对齐两颗按钮的边或摆到网格线上需要的是这种步进。

## 工具按钮

- **与圆形虚线框对齐**：工具按钮的容器原先套用「半个身子缩在后面、悬停滑出来」的平移（`translate-x-1/2`），实际位置比容器盒子右移了半个身位 —— 虚线框量的是容器，于是两者错开 20px，按钮还溢出屏幕右边 4px 点不全。现在这颗按钮不再做那个平移，按钮与容器完全重合（实测容器与按钮左右边界都是 356 / 396）。
- **滑轨方向可自定义**：新增「设置 → 快捷操作 → 工具按钮滑轨方向」，可选 左 / 右 / 上 / 下。原先只能向左滑，而工具按钮贴着屏幕右边缘，向左的轨道会伸出屏幕。改成任意方向后，按住按钮往那个方向划就是同一个动作（打开命令面板）。轨道的几何、填充条的生长方向、手势主轴与触发动画都会跟着换（实测选「上」时轨道为 40×80 且锚在底部）。

## 主页信息条

- **工具坞的尾巴跟着下部分走**：窄缝（compact）里排在「我喜欢的音乐」与账户入口下面那颗「展开 / 折叠信息条」按钮，原先不在 `.bravais-seam-dock` 里，调整「信息条下部分」时它留在原地。现在它使用同一个位移（实测下部分移 +40/+20 时，这颗按钮同样 +40/+20）。头部那颗「折叠」按钮属于上部分，不跟着动 —— 它本来就随「信息条上部分」移动。

## 验证

- 单元测试 82 项全过；改动文件类型检查零报错。
- 实测（412×915）：工具按钮与容器边界一致；滑轨「上」时轨道 40×80 锚底；蒙层四档循环颜色正确（0.55 黑 / 0.62 白 / 0.55 灰）；微调点 3 次左移后偏移精确为 -3px；信息条下部分与尾巴按钮同步位移，头部折叠按钮不动。
