# Folia 0.7.21.22 更新日志

## 四颗浮层按钮

- **默认一样大**：返回 / 定位 / 工具 / 思索原先基准是 40 / 40 / 48 / 48，工具与思索比另两颗粗一圈。现在统一按 40 起算（工具面板与队列浮岛的位置随之收 8px，面板与按钮之间不多出空档）。
- **定位按钮与工具按钮解绑**：定位按钮原先挂在工具按钮上方的竖向弹性列里（`has-above`），拖工具时整列一起动 —— 这就是「拖工具按钮，定位也跟着跑」。现在定位按钮有自己的固定锚点（右下角、工具按钮正上方 12px），有自己的一组偏移，两边的拖动互不影响。顺带：工具按钮被隐藏时，定位按钮仍可单独显示。

## 编辑模式

- **「拖动调整位置」改为一个完整的编辑会话**：在设置里打开后，设置弹窗自动收起，屏幕上出现编辑器。
- **顶部工具栏**：网格开关 / 取消 / 完成。取消把这一轮改动整份还原（位置与大小都还原），完成保留改动。两者都会退出编辑态。
- **边距读数**：选中一个框后，工具栏第二行显示它到屏幕四边的像素距离（左 / 上 / 右 / 下），拖动时实时更新。
- **对齐网格线**：可开关（默认关），20px 细格 + 100px 粗格，用来把按钮摆到同一条线上。开关状态会被记住。
- **贴边与居中**：点选一个框后，底部出现六个动作 —— 左贴边 / 顶贴边 / 右贴边 / 底贴边 / 水平居中 / 垂直居中，按选框当前矩形算位移，只改这一组自己的偏移。

## 验证

- 新增 `wallChromeSnap` 单测（八个贴边/居中用例 + 边距读数），连同原有单元测试共 82 项通过。
- 真机尺寸口径（412×915、触屏模拟）实测：工具按钮 40×40，思索按钮布局 40×40（未展开时 0.94 缩放入场为 38），返回与定位基准同为 40。
- 编辑态实测：工具栏「网格 / 取消 / 完成」单行不换行；选中后读数「左 356 · 上 859 · 右 16 · 下 16」；左贴边 + 顶贴边后按钮到 (0, 0)；水平居中后按钮中心 206 与视口中心 206 一致；取消后回到 (356, 859)。
- 结构实测：`.lattice-tools.has-above` 数量为 0，`.lattice-tools` 内不含定位按钮（定位按钮改由独立槽承载）。
