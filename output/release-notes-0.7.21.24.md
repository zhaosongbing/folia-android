# Folia 0.7.21.24 更新日志

编辑态与设置窗口这一轮，主要是把「浮层位置」从一堆滑杆改成拖拽，并把设置里的选项做成毛玻璃。

## 浮层位置：编辑态里拖，整组一起走

- **主页信息条的下部分整体可拖**：账户入口、工具坞、那颗「展开」尾巴原本只有工具坞跟着动，
  另两颗留在原处；现在三颗合成一组，一个虚线框，拖动整组同步，位置也一起记。
- **Bravais 墙面（集合页 / 海报页）的信息条同样可拖**：完整信息条的两排动作
  （播放全部 / 加入队列 / 收藏，以及列表 / ⋯ 更多）、海报页的底部都归到「下部分」，
  不再各动各的；「上部分」在首页窄缝是标题与页签，在集合页 / 面板 / 搜索页是返回与面包屑。
- **顶部提示改在编辑态里调**：编辑态会画一个提示占位（提示本身是短暂的，平时不在屏幕上），
  拖它就是在调提示的位置；设置里那两个上下 / 左右的滑杆随之移除。

## 长按滑轨不再断触

播放页右下角工具按钮的滑轨（按住往轨道方向划）之前会「拖到一半没了」。三处改动：

- 手势监听从按钮本身搬到 `window`，按 pointerId 只跟按下那一根手指；按钮在手势中被父级
  重渲染、被移位，或者指针被墙面的滚动抢走时，拖动也不会断。
- 长按不再触发文字选择与浏览器右键菜单（Android WebView 上这正是手势被收走的原因）。
- 按下瞬间去掉了「探头」位置的 300ms 过渡 —— 那是按钮在手指下自己滑了半个身位。

## 设置窗口

- **选项与列表改成高斯模糊**：选项卡片、左侧分区列表、下拉列表都跟着面板一起透，
  模糊半径与面板共用「设置弹窗模糊」这一档；面板不透明度也同样作用到它们。
- **浮层设置收拢**：「浮层位置」与「浮层大小」合并成一组「浮层位置与大小」，
  只留「编辑浮层位置」开关、「全部复位」、四颗按钮共用的比例滑杆与它的复位、
  「显示定位按钮」「显示工具按钮」。逐个浮层的十几个滑杆全部去掉 —— 位置在编辑态里拖。
- 补齐了「显示定位按钮 / 显示工具按钮」这两行缺失的中文文案（之前回落成英文）。
- 顶部分组标签下面那条通栏细线去掉了。

## 安装

- 版本 0.7.21.24（versionCode 721024），v2/v3 已签名，可直接覆盖安装。
- 位置相关的存储键没变，之前的调整继续有效。
